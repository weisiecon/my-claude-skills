This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic details and creative choices.

Before coding, commit to a BOLD aesthetic direction: purpose, tone, constraints, and differentiation. Choose an extreme: brutally minimal, maximalist chaos, retro-futuristic, organic/natural, luxury/refined, playful/toy-like, editorial/magazine, brutalist/raw, art deco/geometric, soft/pastel, industrial/utilitarian.

Implement working code (HTML/CSS/JS, React, Vue, etc.) that is production-grade, visually striking, cohesive, and meticulously refined.

Typography: Choose distinctive fonts, avoid Arial/Inter/Roboto/system fonts.
Color: Commit to a cohesive aesthetic with CSS variables.
Motion: Use animations and micro-interactions.
Layout: Unexpected asymmetry, overlap, diagonal flow, grid-breaking elements.
Backgrounds: Gradient meshes, noise textures, geometric patterns, dramatic shadows.

NEVER use generic AI aesthetics: overused fonts, purple gradients on white, predictable layouts.

# Quality Rubric: Respond to Referees

> Scoring rubric for `/respond-to-referees`. Uses the shared framework in [`../../shared/quality-scoring.md`](../../shared/quality-scoring.md).

## Deduction Table

### Blocker (-100)

| Issue | Deduction | Notes |
|-------|-----------|-------|
| Missing response to one or more reviewer comments | -100 | Violates Golden Rule 1 (answer completely) |
| LaTeX does not compile | -100 | Output is unusable |

### Critical (-15 to -25)

| Issue | Deduction | Notes |
|-------|-----------|-------|
| Dismissive or arrogant tone toward a reviewer | -25 | Violates Golden Rule 2; could offend editor |
| Disagreement stated without any supporting evidence | -20 | Violates Golden Rule 3 |
| Fabricated reference (citation that does not exist) | -25 | Academic integrity violation |
| Response addresses wrong point (mismatch with comment) | -15 | Per instance |
| Causal language exceeds the identification strategy | -15 | Per instance |

### Major (-5 to -14)

| Issue | Deduction | Notes |
|-------|-----------|-------|
| Missing manuscript reference when a change was made | -10 | Reviewer cannot verify the change |
| Generic response that could apply to any paper | -10 | Per instance |
| Same response text reused for multiple different comments | -8 | Per duplicated response |
| Compound comment not split into sub-points | -5 | Per compound comment |
| Cover letter omitted when it should be present | -10 | Once |
| Inconsistent comment numbering (does not match reviewer's) | -5 | Per reviewer affected |
| Uses "obviously" or "clearly" when addressing reviewer | -5 | Per instance |
| English prose contains dashes (em, en, or hyphen) | -5 | Per instance |
| Results introduced only in response letter, not in manuscript | -5 | Per instance |

### Minor (-1 to -4)

| Issue | Deduction | Notes |
|-------|-----------|-------|
| Repetitive diplomatic phrasing (same phrase used 3+ times) | -3 | Per repeated phrase |
| Excessive response length for a minor editorial comment | -2 | Per instance |
| Minor inconsistency in formatting between reviewer sections | -2 | Per instance |
| Missing "thank you" in cover letter | -3 | Once |
| Contraction in formal text (don't, can't, etc.) | -2 | Per instance |
| Exclamation mark in formal text | -2 | Per instance |
